Featured Project

Open Access Case Study: Crimetology

A end to end open source Data Science project on how weather shifts spatial crime patterns. Core development tools include an end-to-end spatial-temporal pipeline joining 1.26M policing records with gridded climate observations. Core analytics include to identify micro-scale behavioral patterns using DBSCAN density clustering and binary logistic regression.


Results:

Results indicated that higher temperatures are associated with increased odds of crimes occurring within Leisure environments. Relative humidity demonstrated limited standalone explanatory power but contributed when considered jointly with temperature, suggesting a combined environmental effect consistent with thermal comfort and outdoor activity patterns.
